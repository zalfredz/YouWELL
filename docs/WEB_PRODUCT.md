# Produk web YouWell

Web adalah companion untuk aktivitas di depan laptop, bukan salinan mobile.

| Rute | Fungsi |
| --- | --- |
| `/#/` | Landing publik |
| `/#/app` | Home workspace, Focus Station, Progress |
| `/#/recap` | Ringkasan progress yang aman dibagikan |

Home memakai data core quest yang sama dengan mobile. Focus Station tetap
menjadi tempat Pomodoro/sesi panjang; mobile hanya menyediakan quick focus.
Profile dibuka dari avatar kanan atas.

Admin dan community dashboard tidak ada pada fase ini. Keduanya baru dibangun
setelah autentikasi, role, RLS, dan aturan moderasi server sudah dirancang.
